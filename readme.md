THE MOD:

Custom Appearance Presets: Mod that lets you save and use multiple apperances for your character using a new interface on the antique dresser. Be anyone! Never lose your look again! - 

This mod adds a custom interface to the antique dresser that you can open with a config adjustable key, from this interface you can save, load, export to file and import from your PC character appearences you have set in the default character adjustment menu like hair, skin colour, eye colour, etc. 

The interface then stores that info and lets you swap between any one you would like, allowing an infinite amount of character appearances to be stored for whenever you want to use them, personally I use the mod for changing my character to match the armor im wearing cause its cool and I didnt want to remake it every single time.

Files can be exported to the PC and shared with others who can import them if they wish or if you just want a safer storage for those files for whatever reason. You can adjust the positioning of the tabs in the menu with the settings, the settings also allows you to edit, duplicate, delete, things like that to make the menu easier to customise!
